## 已核对状态

- NVIDIA VAD-TensorRT 项目源码和 first-frame/previous-frame 两套 ONNX 导出脚本存在。
- `plugins/`、`export_eval/`、x86 TensorRT benchmark 入口和 Orin 交叉编译说明存在。
- VAD 是时序模型，首帧和带 previous BEV 的后续帧必须使用不同的 ONNX 输入协议；不能用单一静态 engine 替代两者。
- 官方 README 的 Orin 示例使用 TensorRT 8.6.13.3；这不能直接作为本机 TensorRT 10.9 engine 的精度或延迟验收结果。

4. 复核 scene 边界的 previous BEV/ego pose 递归协议后，再进行 CARLA 闭环测试。
