# UniAD local reproduction handoff

This directory keeps the local RTX 4090 reproduction work alongside the
NVIDIA UniAD source tree. The nested `UniAD/` directory contains the runtime,
diagnostic scripts, and lightweight evidence copied from the handoff branch;
large evaluation artifacts remain in their existing local paths and are
ignored by the canonical DL4AGX Git repository.

Use the PDT-timestamped document at
`/home/lixingfeng/UniAD_examine/DL4AGX/AV-Solutions/docs/4090-UniAD-tiny.md`
as the source of truth for protocol, checkpoint lineage, calibration, and
acceptance status.
